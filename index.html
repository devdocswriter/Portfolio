Case study · Nutanix · 2025

#Docutanix writes the first draft. A person signs off.

Support engineers were spending too long turning tickets into knowledge-base articles. I conceived, built and launched Docutanix, a RAG-powered agent that turns raw drafts, Jira tickets and Slack threads into structured, style-compliant drafts. I designed its content rules myself: the prompts, four embedded style guides, what's internal versus customer-facing, and a mandatory human accuracy review.

Note

AI drafts are only as good as their sources. I also evaluated Glean, Gemini, Agentforce and NXpert against technical references, logged hallucinations, factual errors and terminology drift, and took the evidence to Product and Engineering.

#One paragraph, edited

This is how I review. Marks on the draft, the published version beside it.

Draft · v1

In order to utilizeTo use the API, you will need to kindly first obtainget an authentication token first.1 If the token is expiredexpires, an error may possibly occurthe API returns 401.2 For more information, click hereSee Authentication.3

  1. Cut every word the reader doesn't need.
  2. Which error? Name the condition and the result.
  3. Link text should say where it goes.

Published · v2

To use the API, get an authentication token first. If the token expires, the API returns 401 Unauthorized. See Authentication.

31 → 20 words
1 vague error → 1 status code
