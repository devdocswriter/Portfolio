#Quickstart

Working with me, in three steps. Takes about one sprint to see results.

  1. 1

    Hand me the mess

    Jira tickets, API specs, Slack threads, a half-built feature. I sit with engineers and PMs until the ambiguity is gone.

  2. 2

    I test it first-hand

    Postman, the sandbox, the CLI. If a documented step is wrong, I find out before your users do.

  3. 3

    You ship docs that hold up

    Structured, style-compliant and reviewed. Then I read the analytics and support tickets, and iterate.

Tip

I bring a founder's approach to content: find the unmet need, validate the technology, build systems that scale, ship, measure, iterate.

Guides · Case study · Nutanix, 2025

#Docutanix: an agent that drafts docs

Support engineers kept losing time turning tickets into knowledge-base articles. I conceived, built and launched Docutanix, a RAG-powered agent that turns raw drafts, Jira tickets and Slack threads into structured, style-compliant drafts. It's now Nutanix's most-used internal drafting agent.

Jira + Slackraw context
Glean RAGgrounded sources
Style rules4 guides embedded
Human reviewaccuracy check
10,000+agent runs
263people using it
20–30minutes saved per draft
4tools evaluated: Glean, Gemini, Agentforce, NXpert
docutanix.yaml
agent: docutanix
inputs: [jira, slack, raw_drafts]
retrieval: glean-rag    # cite sources
style_guides: 4
segregation: internal | customer
checks:
  - terminology
  - hallucination
review: human        # always

Warning

AI drafts are only as good as their sources. While evaluating Glean, Gemini, Agentforce and NXpert, I logged hallucinations, factual errors and terminology drift, then took the evidence to Product and Engineering.

#Style guide (excerpt)

I've written four style guides and 30+ guidance modules. Here are three rules I enforce in every review.

✓ Do

Select Save.

✗ Don't

Kindly proceed to click on the Save button in order to save your changes.

Cut every word the reader doesn't need.

✓ Do

If the token expires, the API returns 401 Unauthorized.

✗ Don't

An error may possibly occur in some cases.

Be specific. Name the condition and the result.

✓ Do

Read the authentication guide.

✗ Don't

For more info, click here.

Link text should say where it goes. Screen readers depend on it.
